## 임상 진행률 해석 기준

신약 개발 전체를 단일 퍼센트(%)로 환산한 공식 공시 지표는 **제약업계 표준상 존재하지 않는다** (미검증 — 확인 불가). 일반적 단계별 해석은 다음과 같다:

```
전임상 → 임상 1상(안전성/용량) → 임상 2상(유효성) → 임상 3상(대규모) → 허가 신청 → 상업화
                ↑
         [셀트리온 ADC 3종 현위치]
```

- 임상 1상은 전체 신약 개발 여정의 **초기 단계**에 해당
- CT-P70·CT-P71의 패스트트랙 지정은 FDA 심사 기간 단축 가능성을 의미하나 **임상 성공을 보장하지 않음**
