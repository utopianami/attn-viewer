## 결정 항목 4개 — 설계 제안 (스펙에서 최종 고정)

1. **Stage 1 P1 승인 조건**: 위 화이트리스트/금지 목록 + "각 프로필은 C1 골든셋에서 풀코스 대비 게이트 통과율·근거 커버리지 비열등 확인 후 기본값 채택"을 acceptance criteria로.
2. **RISK lite 필드 위치**: TRIAGE (분류와 동일 콜, 추가 지연 없음) + PLAN 승급 전용 덮어쓰기.
3. **C2/C3 범위**: P2에는 "정책 설계·승인"까지, 구현은 정책 승인을 게이트로 같은 P2 내 후반 배치.
4. **C1 통과 기준**: 초기 골든셋 30~50문항(유형 5종 × 6~10) + 코드 지표(G1~G4 통과율·근거 커버리지·숫자 일치율·라운드 수·비용/지연) + 릴리스마다 수동 샘플링 5문항. 규모는 운영하며 확대.
