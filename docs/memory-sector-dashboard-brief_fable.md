# Memory Sector Dashboard Brief for Fable

작성일: 2026-07-08

## 한 줄 목적

이 화면은 뉴스 모음이나 데이터 전시판이 아니다.

**메모리 산업이 지금 업사이클인지, 둔화인지, 어디가 강하고 어디가 위험한지 한눈에 판단하는 화면**이다.

Raw RAG는 나중 단계다. 지금은 첫 화면에서 산업 상태가 바로 보여야 한다.

## 사용자가 들어와서 바로 알고 싶은 것

첫 화면은 아래 질문에 답해야 한다.

```text
1. 지금 메모리 산업은 좋아지고 있나, 나빠지고 있나?
2. 좋아진다면 수요 때문인가, 가격 때문인가, 재고 때문인가?
3. 나빠진다면 공급 과잉인가, 수요 둔화인가, 가격 하락인가?
4. AI 수요가 실제 메모리 실물 지표로 이어지고 있나?
5. 삼성전자/하이닉스/Micron 주가는 이미 반영했나, 아직 괴리가 있나?
```

## 판단의 기본 논리

메모리 업체 이익은 단순화하면 아래다.

```text
매출 = 출하량 × 가격
이익 = 매출 - 재고/감가/증설 부담
주가 = 미래 이익 기대의 선반영
```

따라서 화면의 중심은 네 가지다.

```text
수요
가격
재고
공급
```

이 네 가지에 직접 답하지 못하는 정보는 메인 화면에 두지 않는다.

## 메인 화면 정보 구조

### 1. 최상단: 오늘의 산업 판단

가장 위에는 점수보다 사람이 읽을 수 있는 결론이 먼저 와야 한다.

예시:

```text
업사이클 유지
수출과 D램 가격은 강하지만, 공급 증설 데이터가 부족해 HBM 과열 여부는 보류.
```

바로 아래에 세 줄을 둔다.

```text
좋은 신호:
반도체 수출 증가 · D램 가격 상승 · 재고 완화

나쁜 신호:
공급 증설 우려 · 일부 AI CAPEX 과잉 뉴스

모르는 것:
HBM ASP · HBM shipment · 공급 capacity
```

`모르는 것`은 중요하다. 없는 데이터를 숨기지 말고 명시해야 한다.

### 2. 핵심 4분면

첫 화면의 핵심은 `수요 / 가격 / 재고 / 공급` 4분면이다.

각 카드에는 아래만 둔다.

```text
상태: 좋음 / 나쁨 / 혼재 / 데이터 부족
대표 지표: 1개
최근 변화: MoM 또는 최근 추세
짧은 해석: 1문장
```

예시:

```text
수요
상태: 좋음
대표 지표: 한국 반도체 수출 01~10
변화: 전월 대비 증가
해석: 삼성/하이닉스 매출 proxy가 개선 중.
```

```text
가격
상태: 좋음
대표 지표: D램 $/GB
변화: 최근 월 상승
해석: 마진 개선 가능성이 커짐.
```

```text
재고
상태: 혼재
대표 지표: 반도체 재고지수
변화: 소폭 하락
해석: 공급과잉 압력은 줄지만 강한 개선은 아님.
```

```text
공급
상태: 데이터 부족
대표 지표: 장비 수주 / HBM capacity
변화: 미연결
해석: 업사이클 판단의 가장 큰 공백.
```

### 3. 인과 사슬

인과 사슬은 설명용이 아니라 `어디서 끊겼는지`를 보여주는 장치다.

표현:

```text
AI 수요
→ 서버/CapEx
→ 메모리 실물
→ 주가 반응
```

각 단계는 핵심 지표 1~2개만 보여준다.

```text
AI 수요:
토큰 사용량 7일 평균

서버/CapEx:
TSMC/Quanta 월매출 MoM
Hyperscaler CAPEX actual

메모리 실물:
한국 반도체 수출
D램 가격
재고지수

주가 반응:
삼성전자/하이닉스/Micron 30일 수익률
```

중요한 출력:

```text
현재 끊긴 곳:
없음 / 서버 단계 약함 / 메모리 실물 미확인 / 주가 과민반응
```

예시:

```text
AI 수요는 강하지만 대만 ODM 월매출이 둔화됨.
→ AI 사용량이 아직 서버 주문으로 충분히 이어졌다고 보기 어려움.
```

## 메인에 반드시 보여줄 지표

아래는 접으면 안 된다. 첫 화면 또는 첫 스크롤 안에 있어야 한다.

| 지표 | 이유 |
| --- | --- |
| 한국 반도체/메모리 수출 | 삼성전자/하이닉스 매출 선행 proxy |
| DRAM/NAND 가격 | 메모리 마진과 사이클 직접 지표 |
| 생산/출하/재고지수 | 공급과잉/업사이클 판단 |
| TSMC/대만 ODM 월매출 | AI 서버 주문 proxy |
| AI 토큰 사용량 | AI inference 수요의 상류 신호 |
| 삼성전자/하이닉스/Micron 주가 반응 | 시장 선반영/괴리 확인 |

## 보조로 내려야 할 지표

아래는 메인 판단에는 약하다. 보조 영역이나 접힘 영역으로 둔다.

| 지표 | 이유 |
| --- | --- |
| 앱 순위 | 메모리 수요까지 경로가 너무 멀고 노이즈가 큼 |
| 토큰 단가 단독 차트 | 단독 해석 불가. 사용량과 결합해야 의미 있음 |
| 뉴스 테마 점수 | 뉴스 설명용이지 산업 상태의 직접 지표가 아님 |
| 일정 캘린더 | 촉매 확인용. 메인 판단 지표는 아님 |

## 앱 순위 처리 원칙

앱 순위는 메인에서 빼는 것이 맞다.

이유:

```text
앱 순위 상승
→ 소비자 관심 증가일 수도 있음
→ 토큰 사용 증가일 수도 있음
→ 서버 부하 증가일 수도 있음
→ HBM 수요 증가일 수도 있음
```

중간에 가정이 너무 많다.

쓰려면 아래처럼 `C0 보조 지표`로만 쓴다.

```text
Consumer AI Usage
ChatGPT US app rank 7일 변화: +2
Gemini KR app rank 7일 변화: -1
```

오늘 순위 자체는 보여주지 않는다.

## 토큰 단가 처리 원칙

토큰 단가는 단독으로 보여주지 않는다.

단가 하락은 두 방향으로 해석된다.

```text
효율화라면:
같은 작업에 필요한 compute 감소
→ GPU/HBM 수요 압박

수요 탄력이라면:
가격 하락으로 사용량 폭증
→ 총 inference spend 증가
→ GPU/HBM 수요 증가
```

따라서 봐야 하는 것은 단가가 아니라 아래다.

```text
Token Spend Direction
= 토큰 사용량 증가율 + 유효 토큰 단가 변화
```

단가 차트는 상세 보조 영역으로 내린다.

## YoY 처리 원칙

YoY는 보조로 둔다.

올해처럼 기저효과가 큰 구간에서는 YoY가 항상 좋아 보일 수 있다. 첫 화면에서는 아래 순서를 우선한다.

```text
1. MoM
2. 최근 3개월 추세
3. 4주 평균 변화
4. QoQ
5. YoY
```

특히 TSMC/Quanta 월매출은 YoY보다 MoM과 3개월 추세를 먼저 보여준다.

## 뉴스/이벤트 처리 원칙

뉴스는 메인이 아니다.

뉴스는 지표 판단을 설명하는 근거로 보여준다.

나쁜 구조:

```text
테마별 뉴스 신호
뉴스 카드 20개
```

좋은 구조:

```text
이 판단을 만든 이벤트
- Amazon debt financing: B축 인프라 투자 긍정
- Microsoft capacity constrained: 서버 수요 긍정
- Meta excess compute: 반대 근거
```

중복 뉴스는 반드시 하나의 이벤트로 묶는다.

예:

```text
이벤트: Amazon $25B debt financing
출처: Bloomberg / Reuters / 기타
영향: B축 CapEx 긍정
중복 기사: 4개
```

## 권장 화면 순서

```text
1. 오늘의 산업 판단
   - 결론
   - 좋은 신호
   - 나쁜 신호
   - 모르는 것

2. 수요 / 가격 / 재고 / 공급 4분면

3. 인과 사슬
   AI 수요 → 서버/CapEx → 메모리 실물 → 주가 반응
   현재 끊긴 곳 표시

4. 핵심 차트
   수출 · D램 가격 · 재고/출하 · 대만 월매출 · 토큰 사용량

5. 판단 근거 이벤트
   dedupe된 뉴스/스피커/공시

6. 보조 데이터
   앱 순위 · 토큰 단가 · 일정 · 전체 카드

7. Raw RAG
   나중 단계
```

## 최종 디자인 원칙

```text
이 화면은 "무엇을 수집했는지"가 아니라
"메모리 산업 상태가 지금 어떤지"를 보여줘야 한다.
```

첫 화면에서 사용자는 아래 문장을 만들 수 있어야 한다.

```text
지금은 수요와 가격은 좋고, 재고는 개선 중이며, 공급 데이터는 부족하다.
따라서 업사이클 판단은 유지하지만 HBM 공급 과잉 여부는 아직 모른다.
```

## 추가하면 좋은 지표

지표는 많이 붙이는 것이 목적이 아니다. 아래 질문에 직접 답하는 지표만 추가한다.

```text
1. 수요가 실제로 늘고 있나?
2. 가격이 따라 오르나?
3. 재고가 줄고 있나?
4. 공급이 과하게 늘고 있나?
5. 시장은 이미 반영했나?
```

### 1. 수요 지표

| 지표 | 왜 필요한가 | 봐야 할 인사이트 |
| --- | --- | --- |
| 한국 메모리 반도체 수출 | 삼성/하이닉스 매출의 직접 proxy | 수출 증가가 뉴스와 같은 방향인지 |
| 한국 반도체 수출 10일/20일 | 월간보다 빠른 선행 신호 | 월초부터 개선되는지, 월말만 좋은지 |
| 대만 ODM 월매출: Quanta, Wiwynn, Wistron, Inventec | AI 서버 조립 수요 proxy | AI 수요가 실제 서버 주문으로 이어지는지 |
| TSMC 월매출 | AI 칩/CoWoS 수요 proxy | AI accelerator 수요가 유지되는지 |
| Nvidia data center revenue | GPU/HBM 수요의 핵심 upstream | HBM 수요가 계속 뒷받침되는지 |
| Broadcom AI semiconductor revenue | custom ASIC/TPU 수요 proxy | Nvidia 외 ASIC 수요가 HBM을 지지하는지 |
| AMD data center / Instinct 매출 | Nvidia 외 GPU 수요 | HBM 수요가 특정 고객에만 의존하지 않는지 |
| Oracle/CoreWeave backlog/RPO | GPU cloud 수요 proxy | 클라우드 AI 수요가 실제 계약으로 남아 있는지 |

수요 인사이트:

```text
AI 뉴스는 좋은데 ODM/TSMC/수출이 안 오른다
= 아직 메모리 실물로 확인 안 됨

ODM/TSMC/수출이 같이 오른다
= AI 수요가 서버와 메모리 실물로 연결 중

Nvidia만 강하고 Broadcom/AMD/ODM이 약하다
= HBM 수요가 특정 체인에 쏠린 것일 수 있음
```

### 2. 가격 지표

| 지표 | 왜 필요한가 | 봐야 할 인사이트 |
| --- | --- | --- |
| DRAM spot price | 사이클 초입 감지 | spot이 먼저 오르고 contract가 따라오는지 |
| DRAM contract price | 메모리 업체 실적에 직접 영향 | 분기 ASP 개선 여부 |
| Server DRAM price | AI/서버 수요와 더 직접 연결 | 범용 PC/mobile이 아니라 서버 수요인지 |
| NAND wafer spot price | NAND 회복 여부 | 감산 반등인지, 수요 회복인지 |
| Enterprise SSD price | 서버/데이터센터 NAND 수요 | AI 서버 저장장치 수요 확인 |
| HBM ASP proxy | HBM 수익성 핵심 | HBM tightness가 가격으로 유지되는지 |

가격 인사이트:

```text
spot 상승 + contract 상승
= 업사이클 확인

spot 상승 + contract 정체
= 단기 채널 수요일 수 있음

server DRAM만 강함
= AI/server 중심 회복. 범용 DRAM과 분리해서 봐야 함

NAND 가격 상승 + SSD 수요 약함
= 감산에 의한 일시 반등 가능
```

### 3. 재고 지표

| 지표 | 왜 필요한가 | 봐야 할 인사이트 |
| --- | --- | --- |
| 한국 반도체 재고지수 | 사이클 고전 지표 | 재고가 꺾이는지 |
| 출하/재고 ratio | 수요가 재고를 흡수하는지 | 출하↑ 재고↓면 강한 업사이클 |
| 생산/출하 spread | 생산이 수요보다 빠른지 | 생산↑ 출하↓면 공급과잉 경고 |
| 삼성/SK하이닉스/Micron DIO | 업체별 재고 부담 | 누가 먼저 재고 정상화되는지 |
| channel inventory 코멘트 | PC/mobile/NAND 재고 | 범용 메모리 회복 여부 |

재고 인사이트:

```text
가격 상승 + 재고 감소
= 질 좋은 업사이클

가격 상승 + 재고 증가
= 공급 부족이 아니라 일시 가격 반등 가능

생산 증가 + 출하 정체
= 다음 분기 가격 압박 위험
```

### 4. 공급 지표

지금 화면의 가장 큰 공백은 공급이다. 공급을 못 보면 업사이클 말기와 공급과잉을 놓친다.

| 지표 | 왜 필요한가 | 봐야 할 인사이트 |
| --- | --- | --- |
| Samsung/SK hynix/Micron CAPEX | 공급 증설 의지 | 모두가 동시에 늘리면 2~4분기 뒤 위험 |
| ASML bookings/backlog | 선단 공정 투자 proxy | 공급 확장이 시작되는지 |
| Applied Materials/Lam/KLA 매출·수주 | 메모리 장비 투자 | DRAM/NAND 증설 신호 |
| HBM capacity 증설 발표 | HBM 공급과잉 위험 | tightness가 언제 풀릴지 |
| TSMC CoWoS capacity | AI accelerator 병목 | HBM 수요가 패키징 병목에 막히는지 |
| substrate/advanced packaging 업체 코멘트 | HBM 공급망 병목 | 물량 확대가 가능한지 |
| 감산/가동률 코멘트 | 공급 discipline | 업체들이 가격을 지키는지 |

공급 인사이트:

```text
수요 강함 + 공급 절제
= 업사이클 질 좋음

수요 강함 + CAPEX 급증
= 단기 좋지만 공급과잉 타이머 시작

HBM capacity 급증 + AI server proxy 둔화
= HBM 프리미엄 붕괴 위험

CoWoS 병목 지속
= GPU/HBM 공급은 타이트하지만 매출 인식은 지연 가능
```

### 5. 시장 반응 지표

| 지표 | 왜 필요한가 | 봐야 할 인사이트 |
| --- | --- | --- |
| 삼성전자/SK하이닉스/Micron 1D/5D/30D | 시장 반영 확인 | 지표 대비 과민/과소 반응 |
| SK하이닉스 vs 삼성전자 상대수익률 | HBM premium 확인 | HBM thesis가 유지되는지 |
| Micron 실적 후 한국 메모리주 반응 | 글로벌 메모리 read-through | 미국 실적이 한국에 어떻게 전이되는지 |
| Nvidia/AMD/Broadcom 반응 | upstream 수요 해석 | GPU/ASIC 뉴스가 HBM으로 전이되는지 |
| SOX/반도체 ETF 대비 초과수익 | 섹터 베타 제거 | 메모리 고유 신호인지 |

시장 반응 인사이트:

```text
지표는 강한데 주가가 약함
= 시장이 공급과잉/밸류에이션/정책 리스크를 보는 중

뉴스는 약한데 주가가 강함
= 이미 나쁜 뉴스가 반영됐거나 지표가 더 중요

SK하이닉스가 삼성보다 계속 강함
= HBM premium이 살아 있음

삼성이 하이닉스를 따라잡음
= HBM 인증/공급 개선 기대가 붙는 중
```

## 추가하면 좋은 파생 인사이트

### 1. Memory Cycle Quality

단순 업사이클 여부가 아니라 업사이클의 질을 본다.

```text
수요↑ + 가격↑ + 재고↓ + 공급절제
= 고품질 업사이클

수요↑ + 가격↑ + 재고↑ + 공급확대
= 취약한 업사이클
```

화면 표시:

```text
Cycle Quality: 강함 / 취약 / 혼재
```

### 2. HBM Tightness

HBM은 spot price가 없으므로 지표를 조합해야 한다.

```text
HBM Tightness =
HBM sold-out 발언
+ 장기 공급계약
+ 고객 인증
+ Nvidia/ASIC 수요
+ CoWoS 병목
- HBM capacity 증설
- AI server proxy 둔화
```

화면 표시:

```text
HBM Tightness: 타이트 / 완화 중 / 데이터 부족
```

### 3. AI Demand Pass-through

AI 수요가 실제 메모리 실물로 전이되는지 본다.

```text
토큰 사용량↑
→ TSMC/ODM 월매출↑
→ 한국 수출↑
→ DRAM 가격↑
```

화면 표시:

```text
Pass-through: 확인됨 / 서버 단계에서 약함 / 메모리 실물 미확인
```

### 4. Supply Overbuild Risk

업사이클 말기를 잡기 위한 지표다.

```text
CAPEX↑
+ 장비 수주↑
+ HBM capacity 증설↑
+ 재고 반등
= 공급과잉 위험
```

화면 표시:

```text
Supply Risk: 낮음 / 상승 / 높음 / 데이터 부족
```

### 5. Stock vs Fundamentals Divergence

주가와 실물 지표의 괴리를 본다.

```text
실물 지표↑ + 주가↓
= 과민반응 또는 시장이 선행 리스크를 보는 중

실물 지표↓ + 주가↑
= 기대 선반영 또는 반등 과열
```

화면 표시:

```text
Market Divergence: 주가 과민 / 주가 선반영 / 지표와 일치
```

## 최종적으로 화면이 보여줘야 할 인사이트 문장

사용자가 차트를 해석하지 않아도 아래 같은 문장이 나와야 한다.

```text
수요는 확인됨:
토큰 사용량과 대만 ODM 월매출이 같이 올라 AI 수요가 서버 주문으로 전이 중.
```

```text
가격은 확인됨:
D램 가격이 상승하고 반도체 수출도 증가해 메모리 실물 지표가 개선 중.
```

```text
공급은 미확인:
장비 수주와 HBM capacity 데이터가 부족해 공급과잉 위험 판단은 보류.
```

```text
주가는 선반영:
하이닉스가 지표보다 빠르게 올라 HBM 기대가 이미 반영됐을 수 있음.
```
