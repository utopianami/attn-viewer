결론 — 토스 안의 데이터만으로도 충분히 강한 리서치 원천을 만들 수 있습니다.

공식 API가 시장의 사실값을, WTS가 재무·수급·뉴스·AI·커뮤니티 맥락을 맡고, 코드는 둘을 시간축으로 결합합니다.

공식 API는 OAuth 2.0 client id/secret이 필요합니다. 현재 환경에는 키가 없어 계약 대조까지만 가능하며, 공식↔WTS live 비교는 키 설정 뒤 수행합니다. WTS는 공개 게스트 세션까지만 허용하고 주문·잔고·계정 로그인 우회는 조사하지 않습니다.

현재 코드와 계약의 갭

  • engine/tools/toss/가 직접 사용하는 고유 WTS 경로는 12개입니다.
  • live smoke는 피드, 회사 번들, 국내 일봉 3개 흐름만 검증하며 국내 분봉은 빠져 있습니다.
  • 투자지표·배당·red flags 일부는 raw dict라 필드 계약과 drift 탐지가 약합니다.
  • 현재 클라이언트는 INFO 호스트 하나만 지원하며 공식 OAuth/CERT/API 호스트 정책은 분리돼 있지 않습니다.
  • 공식 v1.2.4 snapshot·SHA-256 lock·14개 GET allowlist와 계약 테스트는 2026-07-21 추가했습니다.
  • 회사 뉴스 신형 result.kr.content[] 계약과 추출기를 반영해 103자 프리뷰 회귀를 수정했습니다.

확정 구현 순서

  1. market_snapshot — 실시간 랭킹 100, 시장지표, 환율, 거래정보, 경제 이벤트.
  2. signal_snapshot — AI 배치·상세·생성시각·방향·현재 성과.
  3. signal_outcome — Toss 차트만 사용한 1시간·1일·5일 forward return.
  4. community_aggregate — 분당 댓글·고유 작성자·보유표시·반응률만 저장.
  5. official_market_adapter — credential 설정 뒤 공식 14개 GET을 primary로 전환.
  6. 모든 산출물은 storage/users/<username>/toss/ 아래에 상태·계약 버전·수집시각과 함께 저장.
