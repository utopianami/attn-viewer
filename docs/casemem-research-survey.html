과거사례 지식층 — 논문·레포 서베이와 보완 로드맵

우리가 구축한 시스템(bitemporal CaseEpisode · as-of 검색 · 원문대조 검증 · 규칙 증류 · 적대 리뷰)을 기준점으로, 학계·오픈소스에서 검증된 것과 빌려올 것을 정리

0 결론 요약

  • 우리 설계는 방향이 맞다 — 바이템포럴·as-of 차단·원문대조·MAC/FAC 2단이 각각 독립된 최신 연구·상용 시스템과 수렴한다 (§1).
  • 가장 큰 미비점은 "모델 안의 미래 지식" — 문서 시점은 막았지만 LLM 파라미터가 결말을 암기하고 있는 문제(parametric lookahead)는 아직 미방어 (§2 P2-1).
  • 바로 주울 수 있는 과일: SEC 다운로더를 edgartools로 교체, 검증기 2층화(정확일치+의미검증), 평가 골드셋·타임스플릿 체크리스트 (§2 P1).
  • 빈 공간 확인: "bitemporal RAG × 금융 CBR" 교집합의 직접 선행연구는 검색되지 않음 — 우리가 서 있는 지점 자체가 미개척지다.

2 보완 로드맵 (우선순위)

난이도·효과 기준 3단계. P1은 이번 주 수준, P2는 다음 스프린트, P3는 설계 개편급.
순위보완내용 · 근거
P1SEC 다운로더 교체edgartools(v5.43, 2026-07 활성): 10-K/Q/8-K 섹션 추출·XBRL·포맷 변경 추종. 수제 EDGAR 파서 전체 대체. FOMC 백필은 fed-statement-scraping 포크.
P1검증기 2층화1층=자체 exact-match(유지) + 2층=의미 검증: LettuceDetect의 char-offset span 스키마({start,end,text,confidence}) 차용, 인용이 국면 주장을 실제로 지지하는지 저비용(HHEM) 스코어링. "인용은 실존하나 주장과 무관" 케이스 자동 탐지.
P1평가 골드셋 + 편향 체크리스트AnaloBench 교훈: LLM 리랭커를 믿지 말고 국면매칭 골드셋으로 실측. 평가 리포트에 lookahead·생존편향 체크리스트(arXiv:2602.14233·2605.19337) 표준 양식. 다중 레짐 time-split 기본값(arXiv:2505.07078 — 짧은 구간 LLM 알파는 대부분 인공물). ✅ 골드셋 라이브(2026-07-23, 66f38d5): 27문항(evals/casemem_eval.py) — 결정적 hit@1 0.957 / 리랭크 1.0(리랭크 가치 첫 정량 입증), 룩어헤드 프로브 위반 0.
P2파라메트릭 암기 프로브LAP 검정(arXiv:2512.23847): 날짜만 주는 recall 프로브로 "모델이 이 사건 결말을 암기했나" 측정 → 케이스별 오염 플래그. FinCAD(arXiv:2605.24564)식 memory-probe를 적대 리뷰 정식 항목으로.
P2retain 루프 (결과 라벨링)TradingAgents의 outcome-labeled reflection: 케이스 매칭이 리포트에 쓰인 뒤 실현 결과를 조회해 supports_rules/refutes_rules(현재 전부 빈 배열)를 채움. FinAgent식 2단 reflection — 틀렸을 때 "데이터가 달랐나 vs 매핑이 틀렸나" 분리 기록.
P2FAC 기준 = 인과 메커니즘 정렬CANA: 리랭크 프롬프트를 "표면 유사 배제, 수급·정책·심리 메커니즘 정렬로 채점"으로 명시화 + 복수 유추 상호 확인.
P2MAC 하이브리드 키History Rhymes(arXiv:2511.09754): 거시지표 벡터(금리·CPI·빌링 — quant_backbone 확보분)를 토큰 매칭과 결합 → "표면 토큰은 다른데 거시 조건이 같은" 케이스 리콜.
P3fact invalidationGraphiti 4-타임스탬프(valid_at/invalid_at/created_at/expired_at): 후속 문서가 기존 서술을 뒤집을 때 삭제 대신 무효화. qlib PIT의 _next 정정 체인은 공시 정정본 무손실 축적에 그대로 이식 가능.
P3as-of를 쿼리 시맨틱으로QuestDB/DuckDB ASOF JOIN: 앱 로직이 아닌 저장소 계약으로 "timestamp ≤ t 최신 1건". + exchange_calendars로 수집시각을 "사용 가능해진 최초 거래 세션"에 스냅(시간대·휴장 미세 누수 차단).
P3시간융합 검색·감쇠 스코어TempRetriever(시점 메타 임베딩 융합) · FinMem 소스별 감쇠율(뉴스=빨리, 보고서=오래) + 적중 케이스 승격.
⚠ 오픈 리스크: parametric lookahead. 규칙 증류·리랭크에 쓰는 LLM이 2018·2020 결말을 파라미터로 암기하고 있어, 문서 as-of만으로는 백테스트 정직성이 완성되지 않는다. P2-1(암기 프로브)이 방어선.

3 논문 카탈로그 (20편, 전수 URL 확인)

CBR + LLM / 유추 검색

  • DS-Agent (ICML'24) — CBR 사이클로 LLM 개선. retain 단계 참고.
  • CBR-RAG (ICCBR'24) — 필드별 분리 임베딩+hybrid 유사도, "증거로 생성 검증" 프레이밍.
  • AnaloBench — 길고 추상적인 유추에서 LLM 이득 급감 → 리랭커 실측 필요.
  • LLMs for Analogical Reasoning — 후보 생성/구조 판정 분업.

시간적 지식 + RAG

  • Zep: Temporal KG Agent Memory — 바이템포럴 상용 검증, fact invalidation.
  • Temporal IR/QA Survey — 시간 인지 랭킹 카탈로그.
  • TempRetriever — 시간 속성 임베딩 융합.
  • HoH — outdated 정보의 RAG 훼손 정량화.

Lookahead / 누출 편향

  • Detecting Lookahead Bias in LLM Forecasts — LAP 암기 검정.
  • FinCAD 계열 — parametric lookahead 명명·억제(인샘플 수익 -67%p 교정).
  • LLM Strategies Long Run — 편향 통제 시 LLM 알파 소멸.
  • Explicit Bias Consideration — 편향 보고 표준.

금융 메모리 에이전트

  • FinMem — 계층 메모리·감쇠율. DB 수준 as-of 차단은 없음(우리가 더 엄밀).
  • FinAgent (KDD'24) — 이중 reflection.
  • TradingAgents — bull/bear 토론.
  • FinRobot — 플랫폼 계층화.
  • Agentic Trading 리뷰 — 분야 재현성 붕괴 실증, 체크리스트.

역사적 유추 예측

  • History Rhymes — 거시 조건 공동 임베딩 선례 검색.
  • StockMem — 예측→결과→반성 증분 축적.
  • Past Meets Present (ACL'25) — LLM 유추 환각 실측 → verbatim 검증 지지.
  • CANA — 메커니즘 정렬+교차 확인, MAC/FAC의 2026년형 직계.
