WTS 경로는 비공개 내부 API입니다. 공식 문서나 호환성 보장이 없고 예고 없이 경로·스키마가 바뀔 수 있습니다. 읽기 수집만 허용하고 로그인 우회, 주문·잔고 접근, 대량 재판매에는 사용하지 않습니다.

한눈에 보는 결론

토스 안의 데이터만으로도 좋은 리서치 원천을 만들 수 있습니다.

하나의 API에 모든 역할을 맡기지 않고, 공식 시장 데이터와 WTS 해석 재료를 결합한 뒤 계산 가능한 결과는 코드로 파생시키는 구조가 가장 안전합니다.

1

공식 Open API · 시장 뼈대

현재가, 호가, 체결, 상·하한가, 분봉·일봉, 종목 마스터, 환율, 장 캘린더, 랭킹, 지수·국채·투자자 매매대금.

2

WTS · 해석 재료

상세 시세, 재무지표, 배당, 종목 수급, 프로그램 매매, 거래창구, 뉴스 전문, AI 시그널, 커뮤니티, 경제 일정.

3

결정적 파생층

수익률, 수급 변화, 뉴스 중복도, AI 사후성과를 코드로 계산합니다. LLM은 마지막 요약과 해석만 담당합니다.

영역별 소스 선택

겹치는 시장 사실값은 공식 API가 primary, 공식 API에 없는 해석 재료는 WTS가 primary입니다.

WTS 발견 → 공식 검증

검색·종목 식별

WTS 자동완성과 코드 해소로 종목을 찾고, 알려진 symbol의 기본 정보는 공식 계약으로 검증합니다.

공식 primary

시세·호가·체결·차트

공식 API를 기준값으로 사용하고 WTS 상세 필드와 최대 300개 차트 커서를 보강 또는 fallback으로 둡니다.

WTS primary

종목정보·재무·수급

PER/PBR/PSR/EPS/BPS, 배당, 종목별 개인·외국인·기관, 프로그램, 거래창구를 사용하고 공식 시장 수급을 결합합니다.

WTS primary · 증거 B

뉴스

피드 4탭으로 이슈를 발견하고 회사별 기사 전문을 근거 텍스트로 사용합니다. 출처와 기사 시각을 보존합니다.

WTS 보조 · 증거 C

AI 시그널

방향과 이슈 후보만 사용합니다. 생성시각 가격을 고정하고 1시간·1일·5일 수익률로 별도 검증합니다.

WTS 집계 · 증거 D

커뮤니티

원문·닉네임·프로필은 저장하지 않고 댓글 속도, 고유 작성자, 보유 표시, 반응률, 중복률만 시간 버킷으로 집계합니다.

공식 + WTS 병행

랭킹·탐색

공식 시장·체결 랭킹과 WTS 관심도·토스 매수/매도 비율을 서로 다른 신호로 라벨링해 함께 수집합니다.

공식 시장축 + WTS 이벤트축

시장 컨텍스트

공식 환율·KR/US 캘린더·지수·국채에 WTS 시장지표·거래정보·경제 이벤트를 결합합니다.

인증 경계
공식 API는 OAuth 2.0 자격증명이 필요합니다. WTS 공개 GET은 주로 브라우저형 User-Agent로 동작하고, 일부 대시보드 POST는 공개 게스트 세션 헤더가 필요합니다. 계좌·보유자산·주문·개인화 경로는 전부 제외합니다.

소스 품질과 증거 등급

A

사실값

공식 시세·차트·시장정보와 WTS 재무지표·수급. 숫자 주장과 계산의 직접 근거.

B

기사 근거

WTS 뉴스 피드와 회사별 기사 전문. 출처·시각을 보존해 주장 근거로 사용.

C

보조 신호

WTS AI 시그널. 이슈와 방향 후보일 뿐이며 사후성과 검증 전에는 사실로 승격하지 않음.

D

집계 심리

커뮤니티 활동 집계. 사실 근거로 쓰지 않고 개인정보를 즉시 폐기한 집계만 저장.

뉴스 · 핵심 1차 재료

4탭은 이슈 발견, 회사별 상세는 근거 텍스트에 적합합니다. 상세 응답의 result.kr.content[] 스키마 변경도 계약과 테스트에 반영했습니다.

102 탭 노출94 고유 기사20/20 본문 200자+1,488.5자 본문 중앙값

AI 시그널 · 후보 탐지용

응답 성공률은 좋지만 설명 근거 배열이 비어 있고 positive 편향이 큽니다. 별도 forward return 없이는 적중 신호로 보지 않습니다.

56–57 배치 종목12/12 상세 2000/12 근거 배열11:1 positive:negative

랭킹·시장 · 바로 사용 가능

유니버스와 보고서 배경축에 적합합니다. 토스 매수/매도 비율은 전체 시장이 아닌 토스 사용자 표본으로 표시합니다.

100/100 고유 종목10 시장 지표6 미국 지표11 경제 이벤트30초 권장 polling

커뮤니티 · 집계만 허용

활동은 높지만 짧은 글, 재게시, 이미지형 빈 메시지가 섞입니다. 최근순 cursor 연속성을 검사하고 원문·작성자 필드는 즉시 폐기합니다.

110 2종목 표본49+49 고유 작성자11 고정 페이지 크기약 7분 표본 시간폭
  • 모든 수집기는 HTTP 200뿐 아니라 최소 내용 길이, 필수 필드 존재율, 고유 코드 수와 cursor 연속성을 검사합니다.
  • 소스 상태는 ok / degraded / skipped로 기록해 조용한 데이터 손실을 막습니다.

종목별 분당 댓글, 고유 작성자, 보유 표시, 반응률만 수집하고 원문과 식별값은 저장하지 않습니다.

재무제표·공시·컨센서스후순위
WTS 종목정보 하위 탭 XHR을 추가 조사합니다. WebSocket 역추적은 공식 지원 전까지 보류합니다.
저장 계약
모든 실행 결과는 사용자별 storage/users/<username>/toss/ 아래에 저장하고 수집시각, 계약 버전, ok/degraded/skipped 상태를 함께 남깁니다.

공식 계약과 상세 근거

공식 계약은 OpenAPI 3.1.0, API 버전 1.2.4이며 27개 path와 30 operations를 포함합니다. 로컬에는 원문 snapshot과 hash lock을 고정했습니다.

토스증권 Open API 안내 ↗ 공식 개발자 문서 ↗ 공식 LLM 안내 ↗ Canonical OpenAPI JSON ↗ 상세: 공식 API ↔ WTS 갭 분석 상세: 토스 데이터 소스 품질 감사

프로젝트 계약 파일: api-contracts/external/toss/openapi.json · lock.json · read-only-operations.json

종목 식별자 규칙

국내 종목A + 6자리 형식: A005930. ISIN/guid는 KR7005930003이며 커뮤니티·댓글의 subjectId에는 반드시 ISIN을 사용합니다.
해외 종목US-{심볼}(예: US-AAPL) 또는 내부 productCode를 사용합니다. 차트는 us-s 경로입니다.
거래소 메타marketCode의 KSP는 코스피를 뜻합니다. nxtSupported로 넥스트레이드 지원 여부를 확인합니다.
코드 변환 주의회사 뉴스는 6자리 코드, 일반 시세는 A 접두 코드, 댓글은 ISIN을 요구하므로 호출별 식별자를 분리해 보관합니다.

미해결 항목

  • 재무제표·공시·컨센서스: 종목 상세의 “종목정보” 하위 탭 XHR 재캡처가 필요합니다.
  • 실시간 스트리밍: WebSocket URL과 호가·체결 프로토콜이 아직 확인되지 않았습니다.
  • 자동완성: 200이지만 result:[]인 경우가 있어 지역/타입 등 정확한 body 필드를 더 확인해야 합니다.
